# GEN_VIO
这是一个针对自动驾驶汽车和道路场景所开发的通用视觉惯性里程计（GVIO），其能实现同时对汽车的定位和对场景中其他动态物体的3D跟踪（2D跟踪和三维运动估计）。
此项目基于VINS-FUSION系统，进行了深度改造，包括改进道路环境下的特征点提取、匹配、选择和异常值过滤，基于逐层优化机制的相机运动估计，并增加了动态物体的3D跟踪功能。

项目中用到了三个神经网络模型YOLOv8、RapidFLOW和DeepPruner，分别用于实现物体检测与分割、密集光流估计和双目图像间的立体匹配。
如果你有意使用此代码，需要在/TensorRT_engien路径下放置训练后的此三个模型的oonx文件，并在/src/GPUProcess/read_configs.h文件中修改相关参数（如onnx文件名、模型的输入输出变量名）。本工作中使用单个RTX3070显卡(6G内存）同时加载和运行这三个模型（此外还运行SIFT点的检测和匹配），由于GPU在将oonx解析为TensorRT engine的过程中会临时占用很大的内存，因此请确保你的显卡有足够的内存（>5G)能顺利加载所有模型。此外，你可以通过通过序列化的配置参数（如 set_memory_pool_limit）人为限制单个模型在加载时的最大工作空间。
如果你要使用别的网络模型，或者自训练的YOLO-v8所包含的物体类别数和类别顺序与本工作中的默认值有差别，则需要修改/src/GPUProcess下相对应的模型处理文件中的具体函数功能，或者直接创建新的文件并实现对应功能。
